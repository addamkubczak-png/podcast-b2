# Podcast B2

Aplikacja do nauki angielskiego przy okazji: krótkie odcinki do słuchania i powtarzania na głos, postęp względem listy słownictwa A1–B2 (skalibrowanej z Oxford 3000/5000) i powtórki.

Otwórz stronę w Safari na iPhonie i wybierz **Udostępnij → Dodaj do ekranu głównego**. Postęp zapisuje się tylko w telefonie (kopia zapasowa: zakładka Postęp, na dole).

Treść i nagrania generuje skrypt `b2/podcast.py` w głównym projekcie kursu; ten katalog to gotowa aplikacja.
